# COVTrack 轨迹聚合与片段拼接停点（2026-10-24）

本阶段没有新训练，也没有可报告的部署方法收益。只读冻结 COVTrack R50、
官方完整 TAO VAL 预测及 FIT eligible manual-anchor 支持，使用 CPU 和官方 TETA。

## 1. 分类聚合的上限已经识别

发布 TCC 与后验 sumlog 的官方结果为 Base/Novel TETA
`39.554/34.205` 与 `39.774/35.771`；它们只是固定聚合控制，不是新机制。
在 2,912 条 FIT 单 GT 纯轨迹上：众数、sumprob、sumlog 分别为
`0.3723/0.3805/0.3733`。best-frame oracle 为 `0.5295`，但 source-OOF
listwise 重排器退化为 `0.0137`，逐帧可学习加权仅 `0.3822`，oracle 不可据此学习。

诊断发现同轨迹两帧同时分类错误的概率为 `0.653`，独立假设为 `0.113`，
约 5.8 倍簇集；长轨迹没有获得同等的独立证据。512 维 `cls_feat` 可线性重建
`log p_text`（R² `0.967`），log 后验求和与语义嵌入平均后读取基本同构。
这限定了当前固定读出族的头寸，不能据此宣称分类完全不可改进。

## 2. 几何拼接经过三轮检查后停止

帧级 IoU>=0.5 的 GT 接触图只提供 oracle 头寸，不能作为部署候选。
合法排除同帧冲突后，局部 AssocA oracle 为 `0.48391 -> 0.51069`（`+2.68pp`），
不是包含非法同帧合并的 `+5.0pp`。真实 GT-free 候选实现还修复了时间项符号、
同帧重复 ID、int64 溢出和删检测混淆。

最终实现保留全部 1,529,908 个检测，逐分量检查同帧冲突，官方完整 VAL：

| 配置 | Base/Novel TETA | Base/Novel AssocA |
|---|---|---|
| 发布 TCC | **39.554/34.205** | **41.960/40.936** |
| strict disjoint | 39.145/33.887 | 40.387/39.715 |
| medium disjoint | 38.880/33.953 | 39.394/39.879 |

纯几何误并损失大于碎片收益，停止后处理几何拼接。不要把这一负结果外推为
所有带外观、运动或注意力关联模型失败。

## 3. 当前证据下的下一步

真正需要验证的是**部署可见的身份证据**：同一 released ID 内错误外观写入是否
可被过去 raw appearance 与运动状态识别，并在不破坏困难同身份视角的情况下
降低后续级联污染。固定 12-source quarantine 短测仅证明现有 disagreement
拒绝规则过粗：cross-identity 拒绝率 7/38，同身份接受率降至 0.794，不能直接使用。

下一步应先重新检查合法 GT 人口、原 tracker memory 与身份投影，再决定是否进入
可学习的污染路由；不满足强控制/source-OOF 门则不训练。旧分类 sumlog 和 OOF/几何
失败记录保留，不重启它们。
