# COVTrack特征与时空信息改进（2026-10-24）

优先处理源码中可隔离的信息使用问题，再决定是否训练新特征。本阶段已加入独立外观记忆原型和相对时空特征模块；尚无新网络训练、官方TETA或已验证方法收益。冻结上游、发布baseline及另一会话训练不变。

## 1. 外观、语义和位置不要递归混成“外观置信度”

实际调用路径为`OVTrack.simple_test → uncertainty_simple_test → OVTrackerUncertainty.match`。ROI端输出原始256维track embedding和512维语义特征，后者是text/image两头的均值。Tracker用三种cue的cycle consistency决定fusion residual。

`ovtracker.py:531–640`先用当前raw外观与历史memo计算appearance consistency，再融合当前特征；`update_memo:421–424`把这个已融合向量写入EMA。首帧存raw，之后可能存含过去语义/位置残差的fused向量。因此下一帧“appearance confidence”比较的是两种不同来源的状态。训练`ovtrack_roi_head.py:2500–2571`则先在raw key/ref上计算三cue consistency，再融合双方。该数据流差异有源码和独立合成证据；它不是已经证实的性能缺陷。

独立实现`tmp_analysis/context_feature_memory.py`注册`OVTrackerContextMemory`，保留原框/分数/分类及阈值、EMA、生命周期，只改变特征使用方式。五个预定模式全部报告，不据结果选最优：

| 模式 | 改动及诊断问题 |
|---|---|
| released | 调用原super路径；额外raw bank只写不读，验证原版一致性 |
| raw_confidence（首要） | 原fused评分/EMA照旧；独立raw EMA仅计算appearance consistency，隔离历史fusion反馈 |
| raw_only | raw外观直接评分/写入，检测融合是否必要 |
| raw_store_one_sided | 只存raw，仅当前侧临时fusion，分开存储与双侧融合因素 |
| raw_store_symmetric | 从同一pre-update raw快照双向计算confidence，在当前上下文重新融合两侧；临时fused特征不写raw bank |

原型已做三轮合成检查并独立预审，包括原版parity、0残差退化、raw EMA重建、双侧同快照、输入不变、不同候选数、过滤/id=-1及空帧过期。对称版本更接近训练数据流，但EMA历史仍不同于训练单帧reference，不能称完全消除train/inference差异。

## 2. cycle confidence衡量候选歧义，不等于物理可靠性

`CycleLoss.get_pair_consistency`先归一特征、做双向softmax，再取往返矩阵对角。当前/历史各仅一个候选时，`log(1)=0`使两个softmax恒1；即使外观正交或框完全不重叠，cycle confidence仍为1，fusion residual比例`2*(1-conf)^2`为0。一个确定但错误的置换也可往返一致。

因此保留绝对外观cosine/dot和可解释运动相容性，不能只把闭环确定性当正确关联概率。新特征方向必须用同类异身份、外观变化但同身份以及singleton错误候选作挑战；仅提高cycle一致性不算解决问题。

## 3. 用相对运动和实际帧差表达位置

当前位置cue直接把原图绝对`xyxy`做L2归一化/余弦相似度。同一共同平移不改变物体相对运动，却可改变这种confidence；两个成比例的box坐标可以cosine=1而IoU=0。共同均匀缩放下余弦其实不变，不能把平移问题误写成所有缩放都不变性失败。

独立`tmp_analysis/relative_track_geometry.py`实现query×memory的候选对特征：

- 中心差除以双方宽/高几何均值，以及宽高log比例；作为pair edge，不能冒充旧4维node bbox输入。
- 按`original_frame_index`的非等间隔历史估计constant-velocity innovation；`sampled_step`只表示稀疏采样步序。缺fps时单位是原始帧，不称米/秒或真实秒。
- 有明确缺失历史mask；无history输出静态参考IoU，不能当作观测到了零速度。
- 可接每个reference→query的外部homography；历史速度还须previous→reference相机变换。支持接口不等于已实现相机运动估计，更不表示缓存已有相机补偿。

共同平移/轴向缩放、非等间隔、无history、camera warp契约及投影退化均已做合成检查。未把这些新单位塞入原预训练`bbox_transform`，也未加任意运动权重冒称收益。首轮只验证外观记忆，时空输入后续单独对照标准IoU/运动门控，再考虑学习pair融合。

## 4. 小规模真实缓存检验

协议`context_feature_memory_replay_protocol_20261024.json`在真实执行前冻结。数据来自原TAO train与C-TAO原人工anchor交集的固定fit部分；仅按GT-free哈希选12个fit源组、20视频，全部697帧。全部retained行按原顺序输入，不按原emitted ID或GT筛候选。运行原A参数`.37 / memo50 / EMA.4`，从冻结发布checkpoint仅加载原fusion head，CPU执行五模式，不重跑检测器。

缓存raw256/cls512是float16，恢复为CPU float32不能保证原GPU float32轨迹精确一致。因此单列原baseline与重放的逐视频ID/partition差异；所有模式的比较条件于相同量化缓存，不是官方评估。五模式预测全部封存后，才连接固定fit146合法人工anchor身份，按新ID重建稀疏anchor B-cubed；不用旧ID的边/pairs、不把unknown当负例。新ID=-1为独立singleton，原合法anchor分母固定。按源组→GT轨迹→观测等权汇总P/R，再计算harmonic F1；无anchor源组显式报告。

## 6. 真正训练更强特征时的边界

当前缓存足以测试raw256/平均cls512/box/time的使用方式；独立text/image各512维和ROI空间张量未保存，无法从均值唯一恢复。分支融合、局部部件或ROI时空特征需要独立新采集/训练协议。

若上述诊断显示有可信空间，优先考虑冻结开放词汇语义空间，仅在identity路径上训练小adapter/track head，并用跨视角/长间隔同身份正例与同类异身份难负例检验实例区分。候选对网络显式接收相对时空edge，保留缺失/歧义信息；不直接用类别一致性充当身份真值。这些都是待验证设计，普通adapter、对比学习、motion gate和attention已有大量先例，不能仅凭模块组合认定论文新颖性。

一级文献与可辨识性范围见`tmp_analysis/identity_memory_direction_audit_20261023.md`。UGG、Split and Connect等已覆盖不确定身份传播/轨迹分裂；ERM-Track仍为全文访问受阻的待核lead。当前优先级是可验证的代码改进，研究贡献仍需实验和更具体边界。
