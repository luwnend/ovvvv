- 官方 evaluator 的原始 TP/FN/FP 重建 ClsA；逐类 Loc/Assoc 数组不变；ΔTETA=ΔClsA/3。
- 4 个候选评测与 2,000 次 paired 视频重采样均退出 0；receipt、输出 SHA 与保护字段见阶段报告和审计目录。

## GPU 使用规则（硬性）

GPU 编号会随容器/驱动重映射，**不能把旧文档里的 index 当永久映射**。每次启动前现场检查：

```bash
nvidia-smi --query-gpu=index,name,uuid,memory.total,memory.used,utilization.gpu --format=csv,noheader
nvidia-smi --query-compute-apps=pid,process_name,used_memory,gpu_uuid --format=csv,noheader
```

规则：

1. 只使用设备名为 `NVIDIA A100-SXM4-40GB` 的卡；**`NVIDIA DGX Display`（4GB）严格禁止**用于训练/评测。
2. 优先选 `memory.used` 低、且没有他人 compute app 的 A100；不要抢占正在训练的卡。
3. 通过 UUID 固定设备，而不是物理序号：

```bash
export CUDA_VISIBLE_DEVICES=<GPU-UUID-1>,<GPU-UUID-2>
/home/chenhc/miniconda3/envs/covtrack/bin/python - <<'PY'
import torch
print(torch.cuda.device_count())
for i in range(torch.cuda.device_count()):
    print(i, torch.cuda.get_device_name(i))
PY
```

必须全部打印 `NVIDIA A100-SXM4-40GB` 才能继续。
