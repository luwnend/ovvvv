# COVTrack 场景残差信息门（2026-10-24）

## 结论

固定的 12 个 FIT source、20 个视频、697 帧和 677 个相邻帧对上，完整保留每个 query×reference 候选，实际导出 `1,210,939` 个候选；其中 `1,207,931` 个（99.75%）有至少 3 个严格端点排除后的 reciprocal donor。GT-free 导出、pair hash、缺失掩码和独立输出审计均通过。

在此前已经封存的合法 FIT identity 投影上，scene residual 没有超过 raw appearance 的身份区分能力。残差支持的已知候选集合为 `1,743`（558 positive / 1,185 negative；unknown 不作为负例）：

| score（越大越像正例） | AUROC |
|---|---:|
| raw appearance cosine | 0.993939 |
| static displacement `-static_abs_L1` | 0.901171 |
| scene residual `-corrected_L1` | 0.934191 |
| scene gain | 0.604182 |
| 固定反向 residual placebo | 0.065809 |

在同一 residual-supported、每个 query 固定的已知正负候选集合上，raw 正确的 410 个 query 中，scene residual 保留 374、破坏 36；raw 错误的 8 个 query 中修复 3、仍错 5。支持正负两类的 query 共 418 个，覆盖 10 个 source、18 个视频。该读出仍是稀疏合法身份的条件排序，不是完整部署 top1、assignment、TETA 或 tracking 收益。

## 协议与封存

协议为 `tmp_analysis/scene_residual_information_gate_protocol_20261024.json`，脚本为 `tmp_analysis/diagnose_scene_residual_information_gate_20261024.py`，核心残差模块固定为 `all_candidate_scene_residual_20261024.py`。每个 frame-pair 独立输出 `raw_cosine`、`static_abs_L1`、`corrected_L1`、`gain`、`available`、`anchor_count`、`fit_index`、残差向量和 translation；pair receipt 只保存 exclusion/anchor 的轻量 digest，不复制每条 edge 的完整 tuple。

`results/scene_residual_information_gate_20261024_v1/GT_free_residual_sealed.json` 在读取身份前封存；`completion_receipt.json` 状态为 `PASS_SCENE_RESIDUAL_INFORMATION_GATE`。独立审计 `independent_output_audit.json` 检查 677 个 pair 文件、候选总数、raw 来源一致性（最大误差 `7.77e-16`）、`gain = static - corrected`（误差 0）以及 unavailable 的 NaN 掩码，状态为 `PASS_INDEPENDENT_SCENE_RESIDUAL_INFORMATION_OUTPUT_AUDIT`。

## 资源边界

独立只读 preflight 估计全 403 FIT 视频、lag1/lag4 的 `55,352,164` 个候选若按三臂逐 edge 保存，规划约 `15.12 GB`，按 pilot 外推约 `28.36 h`，当前磁盘保留和 12 小时门均未通过，状态为 `HOLD_METADATA_STREAMING_RESOURCE_PREFLIGHT`。因此本阶段只完成固定 12-source 信息门，没有启动全 FIT，也没有为成本保留已知标签行。

## 决策

正确的 scene residual 在这批数据上虽然比 static displacement 好，但仍明显低于 raw appearance，且 repair/break 为 `3/36`。固定反向 placebo 的反向区分结果说明残差数值不是读出缺失；它同时表明直接把 residual 加入身份排序会损害现有外观排序。停止在该 residual 上训练 additive head、ROI transport 或更大时空网络；保留代码、完整 GT-free 候选结果和轻量收据作为普通几何对照。

后续若继续改善时间、空间、外观和位置，应先找到在相同候选和相同 support 上能稳定超过 raw 的可观测增量，再进入独立 source-OOF 和 tracker 闭环。当前没有新方法官方 tracking 收益或论文创新证据。
